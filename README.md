# HANGUL FORM LAB

한글의 형태를 탐색하고 직접 조절해 나만의 워드마크를 만드는 인터랙티브 디자인 도구 (프런트엔드 프로토타입).

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm run build    # dist/ 에 배포용 파일 생성 (정적 호스팅에 그대로 올리면 됩니다)
npm test         # 핵심 로직 테스트
```

## 현재 구현 범위 (1차)

- **자소 조립(선형) 글자 — 프로토타입**: 글꼴 없이 자음·모음을 선(뼈대)으로 직접 정의하고, 모음 종류와 받침 유무에 따라 정한 칸에 규칙으로 조립합니다. 선 굵기, 끝 모양, 꺾임 둥글기, 초성·모음 크기와 간격, ㅇ의 모양(원/네모/마름모)과 열림, 위아래 어긋남을 조절합니다. (`src/core/jamo.ts`)
- **글자별 편집(자소 조립 모드)**: 글자를 눌러 고른 뒤 초성·모음·받침 각각의 크기·가로/세로 이동·회전, 그 글자만의 ㅇ·ㅎ 고리 모양과 열림, 선 굵기를 바꿉니다. 겹받침이 읽히도록 받침 칸을 따로 잡았습니다.
- **자소 뼈대 모양 선택**: ㄱ ㄴ ㄷ ㄹ ㅁ ㅂ ㅅ ㅈ ㅊ ㅋ ㅌ ㅍ ㅎ, ㅏ ㅓ ㅣ ㅗ ㅜ ㅡ에 2~4가지 모양(직각/사선/곡선, 갈라진 ㅅ, 닫힌 ㅂ, 물결 ㅡ 등)이 있고, 같은 자모 전체에 적용하거나 글자 하나만 따로 고를 수 있습니다. 변주 탐색도 이 모양을 바꿉니다.
- **획 연결**: 이웃한 자소(초성-모음, 모음-받침)에서 가장 가까운 끝점과 선을 찾아 직선·곡선으로 잇거나(잇기) 살짝 붙입니다(붙이기). 연결 정도는 전체와 글자별로 조절하고, 변주 탐색도 연결을 흔듭니다.
- **형태 변형 효과**: 거칠게(손으로 오린 듯한 떨림), 물결(위아래/좌우/둘 다), 부풀림(글자마다/단어 전체, 오므림 포함), 줄무늬 잘라내기. 글꼴 모드와 자소 조립 모드 모두에 적용되고 PNG에도 같은 결과로 저장됩니다.
- **그림 첨부**: 투명 PNG(WebP·JPG·SVG 포함)를 글자 뒤나 앞에 올려 크기·위치(끌어서 이동)·회전·투명도·좌우 반전을 조절하고, 저장하는 PNG에 함께 합칩니다. 파일은 브라우저 안에서만 쓰이며 저장·업로드하지 않아 새로고침하면 사라집니다.
- **저장 · 불러오기**: 편집기 위쪽 '저장 · 불러오기'에서 이름을 붙여 브라우저에 저장하는 *내 프리셋*(스타일만 적용 / 이름까지 그대로 열기)과, 이름·디자인·처음 시안·그림을 한 파일(.json)로 내려받고 여는 *작업 파일*을 씁니다. 파일을 열 때는 모든 값을 검사해 허용 범위로 맞추고 알 수 없는 항목은 버립니다.
- **한 획으로 이어 그리기**: 연결 방식 '한 획'은 획의 끝과 끝(닫힌 ㅇ은 한 곳을 풀어서)을 양쪽 진행 방향에 맞는 부드러운 곡선으로 이어 하나의 경로로 합칩니다. 방향이 맞지 않거나 다른 획을 가로지르는 연결, 먼 거리의 어색한 연결은 하지 않습니다. 음절 안에서만 이어집니다. (`src/core/flow.ts`)
- **뼈대 직접 그리기**: 자음·모음의 뼈대를 점으로 직접 고칩니다. 점 끌기, 선 위를 눌러 점 추가/삭제, 꺾임↔부드러움, 획·고리 추가, 좌우/상하 뒤집기, 격자 맞추기. 고친 모양은 그 자모가 쓰인 모든 글자에 적용되고(글자별로 고른 모양이 있으면 그쪽이 우선), 프리셋과 작업 파일에 함께 저장됩니다. (`src/components/SkeletonEditor.tsx`)
- **부리(명조 느낌)**: 획이 시작·끝나는 곳을 작게 꺾습니다. 시작/끝 크기, 직각으로 꺾기·비스듬한 부리, 꺾이는 쪽 반대로. 다른 획에 닿은 끝과 획 연결로 이어진 곳에는 붙지 않고, 짧은 획에는 길이의 일부까지만 붙습니다. 위아래 어긋남은 음수로 두면 반대 방향으로 엇갈립니다. (`src/core/hook.ts`)
- **가로 세로 굵기 대비**: 가로획은 가늘게·세로획은 굵게(명조) 또는 반대로. 획의 방향에 따라 굵기가 변하는 면으로 그려서 ㅇ 같은 곡선은 굵기가 부드럽게 변하고, 부리 끝은 삼각형으로 가늘어집니다. 한 획·연결·부리·효과·PNG 저장과 함께 쓸 수 있습니다. (`src/core/vstroke.ts`)
- **글자 배치 검사**: 기본 설정에서 11,172자 모두 초성·모음·받침이 서로 가로지르거나 8 미만으로 붙지 않는지 테스트로 확인합니다(`src/core/layout.test.ts`). 겹모음·겹받침의 배치와 쌍자음 간격은 이 검사를 기준으로 조정했습니다.
- **끝 가늘게(붓 느낌)**: 열린 획의 시작은 뭉툭하게, 끝은 서서히 가늘어지게 합니다. 굵기 대비·부리·둥글림과 함께 쓸 수 있고, 갤러리에 '붓' 방향이 있습니다.
- **손으로 그리기**: 뼈대 편집기에서 펜·손가락·마우스로 선을 그으면 떨림을 다듬고 점을 줄여 획으로 바꿉니다. 꺾이는 곳은 꺾임, 완만한 곳은 부드러움, 처음과 끝이 만나면 닫힌 고리가 됩니다. 새로 그리기/마지막 획 지우기, 그린 뒤 점 편집으로 이어서 고치기. (`src/core/freehand.ts`)
- **글자별 뼈대**: 뼈대 편집기의 '적용 범위'를 '선택한 글자만'으로 두면, 미리보기에서 고른 그 글자의 자모만 따로 그립니다. 같은 ㄱ도 글자마다 다른 손맛을 줄 수 있고, 우선순위는 글자별 뼈대 > 글자별로 고른 모양 > 모든 글자용 뼈대 > 자모별 모양입니다. 프리셋·작업 파일에 저장됩니다.
- **사용법 안내(?)**: 뼈대 편집기 위의 '? 사용법 보기'를 켜면 각 부분에 번호 붙은 빨간 점이 생기고, 누르면 그 부분의 설명이 열립니다('다음 ▸'으로 차례로 둘러보기). (`SkeletonEditor.tsx`의 `TIPS`)
- **손글씨 흔들림**: 자소마다 기울기·크기·위치, 선의 점마다 위치가 조금씩 달라집니다. 글자 자리별로 결정적(씨앗 고정)이라 새로고침해도 같고, '다시 흔들기'로 다른 흔들림을 고릅니다. (`jamo.ts`의 `wobbleStrokes`)
- **글자별 세부 설정**: 글자 편집에서 선택한 글자만 손글씨 흔들림·부리(시작/끝)·붓 끝 가늘기를 따로 정할 수 있습니다. 정하지 않으면 '전체 설정'을 따릅니다.
- **배경 판**: 조형 효과의 '배경 판'을 켜면 글자 뒤에 색 판(사각형·둥근 사각형·알약·타원·정원)이 깔립니다. 좌우/상하 여백, 모서리 둥글기, 정사각형 맞춤, 판 색을 고르고, 글자색이 '자동'이면 판과 대비되는 흰색/검정으로 정해집니다. 투명 PNG에도 판이 함께 그려집니다. (`src/core/plate.ts`)
- 브랜드명 입력 (NFC 정규화, 지원하지 않는 글자 안내, 12자 제한)
- 형태 탐색 갤러리: 4가지 조형 방향 + 선택한 시안 주변의 변주 탐색(경로 되돌아가기 포함)
- 편집기: 글꼴, 굵기, 폭, 자간, 모서리(둥글게/깎기), 색상
- 조형 효과: 기울기, 세로 비율, 외곽선만, 겹침
- 처음 시안과 비교(현재 / 처음 시안 / 겹쳐 보기), 되돌리기·다시·초기화, 밝은/어두운 배경, 가이드
- 결과 확인과 투명 배경 PNG 내보내기

## 기술 메모

- 글꼴 윤곽선을 fontkit으로 읽어 path로 만든 뒤, 하나의 형상 데이터로 SVG 미리보기와 Canvas PNG 내보내기를 모두 그립니다.
- **폭**은 가로 스케일이며 글꼴의 wdth 축이 아닙니다. 자소 구조를 바꾸지 않습니다.
- **굵기**: 가변 글꼴(Pretendard, Noto Sans/Serif KR)은 wght 축, 고정 글꼴은 외곽선 덧대기(근사)입니다.
- 글꼴은 모두 SIL OFL 1.1이며 `src/data/fonts.ts`에 출처와 라이선스 파일을 기록합니다. 글꼴 준비 과정은 `scripts/prepare-fonts.py` 참고.
- 선택한 글꼴에 없는 글자는 Pretendard로 대체해 그리며 화면에 알립니다.
- `core/`는 React에 의존하지 않는 순수 로직입니다.
